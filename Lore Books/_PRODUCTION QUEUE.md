# LORE BOOK PRODUCTION QUEUE
Ordered by urgency / plot relevance. Check off as built. This is a workflow tracker, NOT canon.

## HOW EACH BOOK GETS MADE (the research packet)
For each book the GM drops a packet; Claude builds a styled `.docx` via a `_build_*.py` script into `Lore Books/`.
A packet = **(1)** a lore source (transcript / article on the subject), **(2)** the voice/angle (who's writing,
from inside what worldview), **(3)** any campaign hook to SEED. Claude cross-checks repo canon automatically;
GM only needs to name a hook when one is wanted.

**House style (locked):** in-voice devotee/partisan text (never neutral encyclopedia); styled docx with title page,
heading rules, indented scripture/quote blocks, and margin annotations from a *second* voice (the counterweight).
Each book gets its own palette. Reviewed line-by-line before file when dialogue/canon claims are involved.
